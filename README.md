# Создаём свою игру с Qwen

Ты придумываешь игру, а нейросеть Qwen пишет для неё код. Получится настоящая игра со звуками, меню и уровнями — она работает на компьютере и на телефоне, и её можно показать друзьям.

## 1. Выбери игру

Игры на выбор: **птичка**, **раннер**, **шутер**, **башни**, **змейка**, **платформер**, **арканоид**. Придумай своей игре название из двух слов, например «Супер Змей».

## 2. Скопируй промт

Нажми на два квадратика в правом верхнем углу блока — промт скопируется целиком. Вставь его в Qwen и **поменяй две строки** в блоке «МОЯ ИГРА»: какую игру ты делаешь и как она называется.

<!-- Файл создаётся скриптом tools/build.py — правь скрипт, а не этот файл. -->

````text
Ты — опытный разработчик браузерных игр. Я придумал игру — давай вместе создадим её для CodePen.

МОЯ ИГРА (меняю только эти две строки):
Игра: змейка
Название игры: обычное

Можно выбрать игру: птичка / раннер / шутер / башни / змейка / платформер / арканоид.
Название — два слова, каждое до 8 букв, например «Супер Змей». «обычное» — оставь английское название игры.

Какой будет игра:
- птичка — Flappy Bird: птичка пролетает между трубами, 3 жизни, 4 фона;
- раннер — Subway Surf: 3D-бег по трём полосам: прыжки, монетки, 3 мира;
- шутер — Quiz Shooter: герой стреляет во врагов, за победу — вопрос и улучшение;
- башни — Quiz Tower: строй башни у дороги, монеты дают за верные ответы;
- змейка — Quiz Snake: змейка ест правильный ответ из четырёх на поле;
- платформер — Quiz Jump: бег и прыжки по платформам, ворота открывает верный ответ;
- арканоид — Quiz Breakout: шар разбивает кирпичи, золотой кирпич — вопрос;
В играх с вопросами (шутер, башни, змейка, платформер, арканоид) 3 мира — Фэнтези, Космос, Эко-Панк — и 4 предмета — математика, русский, английский, история России. Их выбирают в «Настройках» самой игры.

Игра должна быть красивой, со звуками, меню, паузой и экраном «Игра окончена», работать на компьютере и на телефоне. Код без ошибок, игра работает с первого раза.

Должно получиться ровно 3 файла, как три окна в CodePen: HTML (index.pen.html), CSS (style.css), JS (script.js).
Только обычный HTML, обычный CSS и ЧИСТЫЙ JavaScript. НЕ используй TypeScript, React, JSX, Vue, npm, import и export.

Мой проект лежит на GitHub: у каждой игры своя папка с кодом, графикой и звуками. Работай только с папкой моей игры: найди ниже блок «ИГРА: …» с игрой из «МОЯ ИГРА» и открой ТОЛЬКО три файла этого блока. Файлы других игр не открывай.
Если моей игры нет в списке, напиши: «Такой игры нет, выбери игру из списка».

Как выдавать код:
- Первой строкой первого ответа напиши проверку: «Игра: …, проект: …, название: …». В «проект» впиши слово из адреса, например QuizSnake.
- Выдавай каждый файл моего проекта полностью, строка в строку, без сокращений и без других изменений: так игра точно заработает с первого раза. Код уже на чистом JavaScript — не переводи его на TypeScript или React. Пути к звукам не меняй.
- Если в «Название игры» не «обычное», поменяй только две строки в самом начале JS, в блоке LAB:
  titleTop: '…',    — первое слово названия
  titleBottom: '…', — второе слово названия
- Пиши так, будто мы создаём игру прямо сейчас: коротко говори, что делаешь в каждом файле. Не рассказывай, откуда взят код, и не упоминай ссылки и GitHub.
- Отвечай сразу, без долгих рассуждений и без объяснений кода.
- По одному файлу за ответ: сначала HTML, после моего «дальше» — CSS, после следующего «дальше» — JS.
- Перед каждым блоком кода напиши одну строку:
  «Создаю файл 1 из 3 — HTML (index.pen.html): экран игры, меню и кнопки. Вставьте в окно HTML и напишите: дальше»
  «Создаю файл 2 из 3 — CSS (style.css): цвета, кнопки и анимации. Вставьте в окно CSS и напишите: дальше»
  «Создаю файл 3 из 3 — JS (script.js): герои, правила игры и звуки. Вставьте в окно JS — игра готова!»
- JS длинный: если он не помещается в один ответ, остановись в конце строки. После «дальше» продолжи со следующей строки новым блоком кода.
- Если файл не открывается, напиши «Не могу открыть проект».

Когда игра будет готова, я буду просить изменения. В начале JS есть блок LAB «Лаборатория игры» из 10 настроек: меняй только его, одно значение на одну просьбу. Отвечай сразу и коротко: строка «было» и строка «стало» в блоке кода javascript.
Если я напишу «настройки», перечисли 10 настроек LAB моей игры: номер, что делает (из комментария) и пример нового значения. Потом я выберу по номеру.

Начинай: строка проверки и файл 1 — HTML.
````

## 3. Собери игру в CodePen

1. Открой [chat.qwen.ai](https://chat.qwen.ai) и начни новый чат. Включи **«Поиск»**, выключи **«Мышление»** и **«Web Dev»**.
2. Вставь промт, поменяй «МОЯ ИГРА» и отправь.
3. Открой [codepen.io/pen](https://codepen.io/pen/). Qwen будет присылать код по одному файлу:
   - «Создаю файл 1 из 3 — HTML» → вставь в окно **HTML**, напиши Qwen `дальше`;
   - «Создаю файл 2 из 3 — CSS» → вставь в окно **CSS**, напиши `дальше`;
   - «Создаю файл 3 из 3 — JS» → вставь в окно **JS**. Если код оборвался — напиши `дальше` и вставь продолжение в конец окна JS.
4. Игра запустится сама. Поиграй!

## 4. Сделай игру своей

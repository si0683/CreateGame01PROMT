# AGENTS.md — правила для ИИ-агентов

Общий промт урока «Создаём игру»: ученик выбирает игру и название, Qwen берёт готовый шаблон одной из семи игр
(FlappyBird, SubwaySurf, QuizShooter, QuizTowerDefense, QuizSnake, QuizPlatformer, QuizBreakout — github.com/si0683/<имя>, папки рядом в D:\02GameBrowser).

- README.md, PROMPT_QWEN.md и TEACHER.md создаёт `python tools/build.py`: правь скрипт, а не md-файлы. Таблицы «10 изменений» скрипт берёт из PROMPT_QWEN.md каждой игры — после изменения LAB в игре перезапусти его.
- README.md = PROMPT_QWEN.md — страница ученика; TEACHER.md — инструкция преподавателя (проверка, 10 изменений «было/стало», сбои).
- Ученик должен думать, что делает игру сам: в промте и в ответах Qwen нет слов «шаблон», «готовый», «копия»; ссылки поданы как «мой проект на GitHub», Qwen пишет «Создаю файл 1 из 3…». Секреты — только в TEACHER.md.
- Весь промт — ОДИН блок ````text. Ссылки на проекты — полные, отдельным блоком «ИГРА: …» на каждую игру: Qwen плохо подставляет части адреса.
- Название игры меняется только строками `titleTop` / `titleBottom` в LAB — они есть во всех семи играх.
